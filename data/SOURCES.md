# Source provenance

Source metadata and reuse terms were checked on November 9, 2026. The included
source files match both the SHA-256 values in `INPUT_MANIFEST.json` and the
upstream MD5 values listed below. Checksums are verified before each analysis.
The original download date is not independently documented.

## Measurements and annotations

Ernst J et al. **Mapping and analysis of chromatin state dynamics in nine human
cell types.** Nature 473, 43–49 (2011).
[DOI](https://doi.org/10.1038/nature09906),
[PubMed and Figure 1 explanation](https://pubmed.ncbi.nlm.nih.gov/21441907/).

ENCODE Project Consortium. **An integrated encyclopedia of DNA elements in the
human genome.** Nature 489, 57–74 (2012).
[DOI](https://doi.org/10.1038/nature11247).

Histone-mark ChIP-seq measurements were generated by ENCODE/Broad and the
Bernstein laboratory; segmentation was produced by the Kellis group. ChromHMM
learned a common 15-state model from nine factors plus input, using binarized
200-bp observations. We reuse published state assignments and do not retrain
that model. Lifted boundaries are not necessarily multiples of 200 bp.

## Terms and changes

[ENCODE data-use policy](https://genome.ucsc.edu/ENCODE/terms.html) permits
download, analysis and publication of released data, requesting investigator,
Consortium and accession attribution. Both records list restrictions ending
March 16, 2011. The track page additionally states there is no restriction on
segmentation data. Do not describe these files as CC0 or as covered by our code
license.

Raw source files are unchanged and included for offline reproducibility.
Derived outputs select chr22; intersect covered territory; split at both tracks'
boundaries; exclude states 14/15 in either line for the primary mask; aggregate
base-pair coverage, regulatory-class overlaps and paired states. The alternative
mask retains states 14/15. State 13 is retained in both. No missing annotations
are imputed. Full raw row counts are reported, while overlap, gap and duplicate
checks apply specifically to selected chr22 records. This is a secondary
analysis, not newly generated ChIP-seq or a new ChromHMM training dataset.
