04 / Sensitivity analysis

Does the choice matter?

Both masks and both enhancer definitions are shown. Broadening enhancer states changes the biological question.

Definitions and denominators

Primary territory intersects both source tracks and removes any base assigned state 14 or 15 in either line. The sensitivity territory keeps these annotations where both tracks cover. Active promoters are state 1. Strong enhancers are states 4/5; broad enhancers also include weak/poised states 6/7. Retention = shared bases divided by that line’s class coverage.

06 / Evidence and interpretation

What this comparison can establish

This secondary analysis measures cell-type specificity in published ChromHMM state assignments. Histone-mark ChIP-seq provides experimental signals; the state labels are model-derived candidate annotations. GM12878 is a lymphoblastoid line and K562 is an erythroleukemia line. Lineage, transformation, culture, assay variation, and state-calling uncertainty can all contribute to the difference.

Lower enhancer sharing is consistent with context-dependent regulatory programs. It does not prove enhancer function, identify target genes, measure remodeling rates, or establish a differentiation trajectory. Chromosome 22 is a restricted genomic sample, and neither bases nor adjacent intervals are independent biological replicates. No inferential p-values are reported.

A proposed follow-up is to test selected shared and cell-specific candidate enhancers in both cellular contexts using matched functional assays. This is a proposal, not an experiment performed here.
