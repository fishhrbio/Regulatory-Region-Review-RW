# Project overview

**Waite Chromatin Atlas**  
Robert Waite · M.S. candidate in Biotechnology · USF

This project explores how candidate gene-regulatory regions differ between two
human cell lines. Using public ENCODE chromatin-state annotations, it compares
active promoters and strong enhancers on chromosome 22 and measures how much
of each regulatory class is shared.

Across 31.47 million eligible DNA bases, active promoters show 47.4% Jaccard
overlap, while strong enhancers show 7.3%. The ordering remains consistent when
the analysis includes repetitive/CNV annotations or broadens the enhancer
definition. This supports a descriptive pattern of greater enhancer annotation
specificity in the two cell lines.

An interactive explorer makes the comparison accessible through coverage
charts, sharing bars, a paired-state map, genomic interval inspection and
downloadable results. Reproducible code, an executed notebook, quality checks
and source provenance accompany the visual results. The analysis compares
published annotations; it does not directly test enhancer function or measure
changes over time.
